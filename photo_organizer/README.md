# 사진 정리 도우미 (휴대폰 갤러리 정리)

뒤죽박죽인 휴대폰 갤러리를 쉽게 정리하도록 도와주는 프로그램입니다.
설치가 필요 없고, 휴대폰이나 컴퓨터의 **인터넷 브라우저에서 바로 열어서** 씁니다.

## 할 수 있는 것

1. **날짜별 모음** — 사진을 불러오면 촬영일(EXIF) 기준으로 년·월·일별로 자동 정렬. 위쪽 월 버튼으로 바로 이동
2. **테마별 모음** — 음식·풍경·인물 같은 테마에 사진을 눌러서 착착 분류. 스크린샷/동영상은 자동 분류 (지원 기기에서는 인물 사진도 자동 인식)
3. **정리해야 될 사진 자동 찾기**
   - 중복·비슷한 사진 (연속 촬영 묶음, 가장 좋은 1장 추천)
   - 스크린샷 / 흐릿한 사진 / 너무 어두운 사진 / 용량 큰 파일
   - 지울 사진은 "정리함"에 담고, 마지막에 **삭제 목록**을 복사해서 갤러리 앱에서 지우면 끝
4. **쉬운 검색** — 파일명·테마·날짜(예: `2025`, `8월`)·종류(사진/동영상/스크린샷)·즐겨찾기로 바로 찾기

## 사진을 한 번에 왕창 불러오기

휴대폰 보안 규칙상 웹 앱은 갤러리를 통째로 읽을 수 없어서 "직접 고른 사진"만 받을 수 있습니다. 대신:

- **안드로이드(갤럭시)**: [사진 추가] → 선택 화면에서 갤러리 대신 **「내 파일」 앱** 선택 → 내장 저장공간 → **DCIM → Camera** → 오른쪽 위 **⋮ → 모두 선택** → 완료
- **아이폰**: 사진 선택 화면에서 손가락을 떼지 않고 드래그하면 여러 장이 한 번에 선택됩니다
- **컴퓨터**: 첫 화면의 **[폴더째 불러오기]** 버튼, 또는 사진 파일을 화면에 끌어다 놓기
- 나눠서 여러 번 불러와도 **같은 사진은 자동으로 합쳐집니다** (앱 첫 화면과 검색 탭의 도움말 버튼에도 같은 안내가 있어요)

## 사용법

1. 휴대폰에서 앱 링크를 엽니다 (또는 이 폴더의 `index.html`을 브라우저로 열기)
2. **[사진 추가]** → 갤러리에서 정리할 사진을 여러 장 선택
3. 아래 탭(사진첩 / 테마 / 정리 / 검색)을 오가며 정리
4. 처음이라면 **[샘플 사진으로 구경하기]** 를 눌러 기능을 먼저 체험해 보세요

## 자동 저장 (v2)

- 불러온 사진의 **미리보기·날짜·분석 결과·정리 상태가 기기 브라우저에 자동 저장**됩니다. 앱을 껐다 다시 열어도 정리하던 화면이 그대로 복원됩니다.
- 복원된 화면은 미리보기 화질입니다. **[사진 추가]로 같은 사진을 다시 선택하면 원본 화질로 다시 연결**되고, 중복으로 쌓이지 않습니다.
- 저장은 **기기(브라우저)별**입니다. 다른 폰에서는 따로 시작하고, 브라우저 데이터를 삭제하면 기록도 사라지므로 검색 탭의 **[기록 백업하기 / 백업 불러오기]** 를 가끔 이용하세요.
- 갤러리에서 삭제를 마쳤다면 정리함의 **[갤러리에서 삭제 끝냈어요]** 버튼으로 목록을 비우면 됩니다.

## 안심하고 쓰세요

- **사진은 휴대폰 밖으로 나가지 않습니다.** 인터넷 업로드 없이 전부 기기 안에서만 처리됩니다. (링크를 공유해도 각자 자기 기기에만 저장됩니다)
- 이 프로그램은 **원본 사진을 절대 지우지 않습니다.** "정리함"은 목록일 뿐이고, 실제 삭제는 본인이 갤러리 앱에서 합니다. (브라우저는 보안상 휴대폰 파일을 직접 삭제할 수 없습니다)

## 알아두면 좋은 점

- 한 번에 수백 장씩 나눠서 정리하는 것을 추천합니다 (수천 장도 되지만 불러오는 데 시간이 걸립니다)
- 아이폰 HEIC 등 일부 형식은 미리보기가 안 될 수 있지만 목록·날짜 정리에는 포함됩니다
- 휴대폰 브라우저 메뉴의 **"홈 화면에 추가"** 를 쓰면 일반 앱처럼 아이콘으로 열 수 있습니다

## 기술 메모 (개발용)

- 단일 HTML 파일 (`index.html`), 외부 라이브러리 없음
- EXIF 촬영일 직접 파싱(JPEG), 중복 감지는 가로+세로 dHash 지문 + 밝기 조건, 흐림 감지는 라플라시안 분산(전체 중앙값 대비 상대 기준)
- 자동 저장은 IndexedDB 2개 스토어(photos: 썸네일+분석 결과 / records: 테마·즐겨찾기·정리함), 키는 파일명+크기+수정시각 — 저장이 안 되는 환경에서도 앱은 정상 동작
- 백업은 정리 기록(JSON)만 내보내며, 사진·썸네일은 포함하지 않아 파일이 작음
