# 일본 영상 검토 프로그램 (Vrew용)

완성한 일본어 유튜브 영상이 제대로 만들어졌는지 자동으로 검토합니다.

## 검사하는 것

1. **자막 ↔ 대본 대조** — 빠진 문장, 오타로 달라진 문장, 순서 뒤바뀜
2. **이미지 ↔ 영상 매칭** — 안 쓰인 이미지, 씬 순서 어긋남, 매칭표 대비 등장 타이밍 어긋남
3. **자막 위치 점검** — 자막 위치가 들쭉날쭉한 구간 (+ 눈으로 확인용 화면 타임라인)
4. **일본어 자연스러움** — 번역투/어색한 표현/경어 불일치를 원어민 편집자 관점으로 검토

## 처음 설정 (딱 한 번만)

> 먼저 Python이 설치되어 있어야 합니다. https://www.python.org/downloads/ 에서 설치할 때
> **"Add Python to PATH"** 체크박스를 꼭 켜 주세요.

**`install.bat` 더블클릭** — 필요한 부품을 설치합니다.

## 사용법

1. 폴더 하나에 검토 자료를 모아 넣습니다:
   - **영상**: mp4 파일 (Vrew에서 내보낸 완성본)
   - **이미지**: 영상에 쓴 씬 이미지들 (파일명에 씬 번호가 있으면 순서 검사됨. 예: `scene1.png`, `1.png`)
   - **대본**: 파일명에 "대본"이 들어간 txt
   - **자막**: Vrew에서 [파일 → 다른 형식으로 내보내기 → **자막파일(.srt)**] 로 내보낸 srt ← 꼭 넣어주세요
   - **매칭표**: 파일명에 "매칭" 또는 "씬"이 들어간 txt/xlsx (씬번호 + 그 씬의 대본 시작 문구)
2. **`review.bat` 더블클릭** → 그 폴더를 창에 드래그해서 놓고 Enter
3. 끝나면 폴더 안에 생긴 **`검토보고서.html`** 을 더블클릭 → 오류/확인필요 목록이 정리되어 나옵니다.

## 일본어 자연스러움 자동 검토 켜기 (선택)

- 프로그램 폴더에 `api_key.txt` 파일을 만들고 [Anthropic API 키](https://console.anthropic.com/)를 넣어두면,
  실행할 때마다 Claude가 대본 전체를 원어민 편집자 관점으로 자동 검토해서 보고서에 넣어줍니다.
  (대본 1편당 비용 대략 몇백 원 수준)
- 키가 없으면 대신 `자연스러움_검토요청.txt` 파일이 만들어집니다.
  이 파일 내용을 **Claude 앱에 붙여넣으면** 같은 검토를 무료(구독 안에서)로 받을 수 있습니다.

## 참고

- 자막 위치 자동 검사는 OCR(Tesseract 일본어)이 설치된 경우에만 동작합니다.
  설치하지 않아도 보고서 맨 아래 "자막 화면 타임라인"으로 위치를 한눈에 훑어볼 수 있습니다.
- 영상이 길수록 분석에 시간이 걸립니다 (30분 영상 기준 몇 분 정도).
