## 📱 사진 정리 도우미 — 갤럭시 설치 방법

아래 파일 **PhotoOrganizer.apk** 를 받아서 설치하면 됩니다. (플레이스토어에 없는 개인용 앱이라, 처음 한 번만 "허용" 단계가 있어요.)

### 설치 순서 (휴대폰에서)

1. 이 화면 아래쪽의 **「PhotoOrganizer.apk」** 를 누르세요 → 내려받기가 시작돼요.
2. 내려받기가 끝나면 알림(또는 크롬 아래쪽)의 **「열기」** 를 누르세요.
3. "출처를 알 수 없는 앱" 이라는 안내가 나오면 → **「설정」** → **「이 출처 허용」** 을 켜고 → 뒤로가기.
4. **「설치」** 를 누르세요.
5. 설치가 끝나면 **「열기」** → **「허용」** (사진 접근 권한) 을 누르세요.
6. 끝! 갤러리 전체가 자동으로 들어와요. 홈 화면의 **「사진 정리」** 아이콘으로 언제든 열 수 있어요.

### 웹(크롬) 버전과 무엇이 다른가요?

- 사진을 고르거나 ZIP으로 넣을 필요 없이 **갤러리 전체가 자동으로** 들어와요.
- 폴더를 만들면 **갤러리에 진짜 앨범이 바로** 생겨요. (압축 해제 필요 없음)
- 정리함에 담은 사진은 **앱에서 바로 삭제**돼요. 확인창 한 번이면 끝. (삭제한 사진은 갤러리 휴지통에 30일 보관되니 실수해도 되살릴 수 있어요)
- 사진은 **휴대폰 밖으로 절대 나가지 않아요.** 인터넷은 오직 "새 버전 확인·내려받기"에만 쓰이고, 사진이나 정리 기록은 그 어떤 것도 전송되지 않아요.

### 이미 설치했다면, 새 버전은 앱이 알아서 알려줘요

새 버전이 나오면 앱 사진첩 위에 **「🎁 새 버전이 나왔어요!」** 배너가 떠요. **「업데이트」** 만 누르면 앱이 스스로 내려받아 설치 화면을 열어 줘요 (정리 기록 그대로 유지). 이 페이지에서 다시 받을 필요가 없어요.
