# 네이버 카페 글 캡쳐 프로그램

로그인해야만 볼 수 있는 **네이버 카페 글**을, 링크만 넣으면 자동으로:

1. 화면 전체를 **스크린샷**으로 저장하고
2. 제목 · 작성자 · 본문 · 이미지를 뽑아서
3. **보기 좋은 HTML 정리본** 파일 하나로 만들어 줍니다.

비밀번호를 이 프로그램에 입력할 필요가 없습니다.
처음 한 번, 프로그램이 열어주는 브라우저 창에서 **직접** 네이버에 로그인하면
그 로그인 상태만 내 컴퓨터(`browser_profile` 폴더)에 저장되고, 이후에는 링크만 넣으면 됩니다.

---

## 처음 설정 (딱 한 번만)

> 먼저 Python이 설치되어 있어야 합니다. https://www.python.org/downloads/ 에서 설치할 때
> **"Add Python to PATH"** 체크박스를 꼭 켜 주세요.

1. **`install.bat` 더블클릭** — 필요한 부품을 설치합니다. (몇 분 걸릴 수 있어요)
2. **`login.bat` 더블클릭** — 브라우저 창이 열리면 네이버에 로그인하세요.
   화면에 "로그인 확인 완료!"가 뜨면 끝입니다.

## 사용법

### 여러 글을 한번에 (추천)

**`capture_all.bat` 더블클릭** → 메모장이 열리면 캡쳐할 주소들을 전부 붙여넣기
→ 저장(Ctrl+S)하고 메모장 닫기 → **자동으로 전부 캡쳐됩니다.**

- 한 줄에 하나씩, 개수 제한 없습니다. 명령어를 칠 필요가 전혀 없습니다.
- 붙여넣은 주소는 `links.txt`에 남아 있으니, 다음에 또 실행하면 내용만 바꿔서 쓰면 됩니다.

### 한 개만

**`capture.bat` 더블클릭** → 카페 글 주소를 붙여넣고 Enter.

### 결과 확인

결과는 `output` 폴더 안에 글마다 폴더가 하나씩 생깁니다.

- `정리본.html` — 더블클릭하면 보기 좋게 정리된 글이 열립니다. (이미지 포함, 이 파일 하나로 공유 가능)
- `screenshot.png` — 원본 화면 전체 스크린샷

명령어로 쓰고 싶으면:

```
python naver_capture.py "https://cafe.naver.com/카페이름/글번호"
python naver_capture.py --file links.txt            ← 메모장 파일에 있는 주소 전부
python naver_capture.py --show "주소"               ← 브라우저 창을 보면서 캡쳐
```

## 자주 묻는 문제

| 증상 | 해결 |
|---|---|
| "로그인이 되어 있지 않습니다"라고 나옴 | `login.bat`을 다시 실행해서 로그인하세요. (로그아웃했거나 세션이 만료된 경우) |
| 본문 영역을 찾지 못했다고 나옴 | 멤버 등급 제한 글일 수 있습니다. 스크린샷은 저장되니 확인해 보세요. `--show` 옵션으로 다시 시도해도 됩니다. |
| 한글이 깨져 보임 | 명령 창에서 `chcp 65001` 입력 후 다시 실행하세요. (bat 파일은 자동 처리됩니다) |
| 모바일 주소(m.cafe.naver.com)를 넣었어요 | PC 주소(cafe.naver.com)로 바꿔서 넣어 주세요. |

## 주의

- `browser_profile` 폴더에는 내 네이버 로그인 상태가 들어 있습니다. **다른 사람에게 보내거나 인터넷에 올리지 마세요.**
- 캡쳐한 글은 개인 보관용으로만 사용하세요. 남의 글을 무단으로 재배포하면 저작권 문제가 될 수 있습니다.

# 일본 영상 프로젝트 검토 프로그램

일본어 유튜브 영상 재료(대본 · 이미지 · 자막 · 씬 매핑 · 오디오)를 한 폴더에 모아두면,
**업로드 전에 문제가 없는지 자동으로 전부 검토**해서 보기 좋은 리포트(`검토리포트.html`)를 만들어 줍니다.

## 처음 설정 (딱 한 번만)

**`install_review.bat` 더블클릭** — 필요한 부품을 설치합니다.
(네이버 캡쳐 프로그램용 `install.bat`을 이미 돌렸어도, 이걸 한 번 더 실행해 주세요.)

## 사용법

1. 영상 하나에 들어가는 재료를 **폴더 하나**에 모읍니다. (아래 "폴더에 넣는 것" 참고)
2. **그 폴더를 `review.bat` 파일 위로 드래그**합니다.
   (또는 `review.bat` 더블클릭 → 폴더 경로 붙여넣고 Enter)
3. 검토가 끝나면 그 폴더 안에 `검토리포트.html`이 생기고 자동으로 열립니다.
   - ❌ **오류** = 이대로 업로드하면 사고 나는 것 (꼭 고치세요)
   - ⚠️ **주의** = 확인해보면 좋은 것
   - ✅ **통과** = 문제 없음

> 처음이라면 `sample_project` 폴더를 드래그해 보세요.
> 일부러 문제를 심어둔 연습용 폴더라서, 검토가 어떻게 나오는지 바로 볼 수 있습니다.

## 폴더에 넣는 것 (있는 것만 넣으면 됩니다)

| 재료 | 파일 | 비고 |
|---|---|---|
| 대본 | 파일명에 `대본`이 들어간 `.txt` | 일본어 TTS에 넣을 최종 대본 |
| 이미지 | `images` 폴더 안에 `001.png, 002.png ...` | 폴더 없이 그냥 넣어도 됩니다 |
| 자막 | `.srt` 또는 `.ass` | `.ass`면 자막 위치까지 검사합니다 |
| 씬 매핑 | `06_scene-mapping.txt` | 스킬이 만들어준 씬별 대본 시작 지점 파일 |
| 스토리보드 | `05_image-prompts.xlsx` | 스킬이 만들어준 이미지 프롬프트 파일 |
| 오디오 | `.mp3` / `.wav` | TTS로 뽑은 나레이션 |
| 동영상 | `.mp4` | 완성본이 있으면 길이 비교까지 합니다 |
| 타임라인 | 파일명에 `타임라인`이 들어간 `.csv`/`.xlsx` | 씬·파일·시작(초)·길이(초) 표 |

없는 재료의 검사는 자동으로 건너뜁니다. 대본만 넣고 돌려도 됩니다.

## 무엇을 검사하나요?

- **대본**: 한글 혼입(TTS 사고 방지) · 글자수와 예상 영상 길이 · 너무 긴 문장 · です・ます체 통일 ·
  마크다운/지시문 잔재 · 이모지 · 반각 가타카나 · 똑같은 문장 반복
- **이미지**: 깨진 파일 · 번호 누락/중복(001, 002, 004 ← 003 빠짐) · 해상도와 16:9 비율 ·
  해상도 섞임 · 생성 실패로 보이는 작은 파일
- **자막**: 시간 겹침/역전 · 너무 빠른 자막(읽을 수 없는 속도) · 한 줄 글자수 · 3줄 이상 ·
  빈 자막 · 한글 혼입 · (`.ass`) **자막이 화면 밖이거나 위쪽에 있어 이미지를 가리는지**
- **씬 구성**: 씬 수 = 이미지 수인지 · 씬 시작 문구가 대본에 실제로, 순서대로 있는지 ·
  스토리보드 프롬프트 빠짐/중복
- **길이 정합**: 대본 분량 ↔ 오디오 길이 · 자막 끝 ↔ 오디오 끝 · 오디오 ↔ 동영상 ·
  타임라인의 겹침/빈 구간/총 길이
- **동영상 내용** (완성본 .mp4를 실제로 열어서 검사):
  씬 전환 시점 감지 · **각 장면이 어떤 이미지인지 대조해서 빠진 이미지/순서 뒤바뀜 찾기** ·
  타임라인 표와 실제 전환 시점 비교 · **자막이 실제 화면 어디에 표시되는지**
  (안 보이는 자막, 화면 위쪽에 떠서 이미지를 가리는 자막, 화면 끝에 붙은 자막)

> 동영상 내용 검사를 체험해 보려면 `sample_video_project` 폴더를 드래그해 보세요.
> 일부러 문제를 심어둔 짧은 영상(완성본.mp4)이 들어 있습니다.

명령어로 쓰고 싶으면:

```
python japan_review.py "프로젝트폴더"
python japan_review.py "프로젝트폴더" --cpm 300     ← TTS가 느리면 분당 글자수 조정
python japan_review.py "프로젝트폴더" --no-open     ← 리포트를 자동으로 열지 않음
```

# 제미나이 TTS 목소리 테스트

제미나이(구글) TTS로 **같은 일본어 문장을 목소리 6종으로** 만들어 줍니다.
들어보고 마음에 드는 목소리를 고르면, 나중에 만들 "TTS + 캡컷 자동배치 프로그램"에 그 목소리를 설정합니다.

## 준비물

- 제미나이 API 키 — https://aistudio.google.com/api-keys 에서 발급 (`AIza...`로 시작하는 문자열)

## 사용법

1. **`tts_test.bat` 더블클릭**
2. 처음 한 번만: API 키를 붙여넣고 Enter → `api_key.txt`에 자동 저장됩니다.
3. 잠시 기다리면 `목소리샘플` 폴더가 열리고 wav 파일 6개가 들어 있습니다.
4. 하나씩 들어보고 **마음에 드는 파일 이름(목소리 이름)** 을 기억해 두세요.

## 주의

- **`api_key.txt`는 절대 다른 사람에게 보내거나 인터넷에 올리지 마세요.** (내 구글 계정으로 요금이 청구되는 열쇠입니다)
- "무료 한도" 오류가 나면: 무료 등급은 하루 요청 횟수가 적습니다. 다음 날 다시 하거나, AI Studio에서 결제 연결(종량제)을 하면 해결됩니다.

# 제미나이 TTS + 캡컷 자동배치

프로젝트 폴더(대본 + 씬 매핑 + 이미지)를 넣으면:

1. 대본을 씬별로 나누고
2. **씬마다 제미나이 TTS로 일본어 나레이션을 생성**하고 (목소리 30종 중 실행할 때마다 선택)
3. 씬별 오디오 길이에 딱 맞춘 **자막(srt)과 타임라인(csv)** 을 만들고
4. **캡컷 초안을 자동 생성**해서 이미지·오디오·자막을 타임라인에 전부 깔아 줍니다.

캡컷을 열면 초안 목록에 나타나고, 열어서 확인 → 내보내기만 하면 영상이 완성됩니다.

## 준비물

- `install_review.bat` 을 한 번 실행했을 것 (필요한 부품이 같이 설치됩니다)
- 제미나이 API 키 (`tts_test.bat` 을 먼저 써봤다면 이미 저장되어 있습니다)
- 프로젝트 폴더: 파일명에 `대본`이 들어간 .txt + `06_scene-mapping.txt` + `images` 폴더(001.png ...)
  - 씬 수와 이미지 수가 같아야 합니다 (`review.bat` 으로 미리 확인 추천)

## 사용법

1. **프로젝트 폴더를 `자동배치.bat` 위로 드래그** (또는 더블클릭 후 경로 붙여넣기)
2. 목소리 번호 선택 (그냥 Enter = 지난번 목소리) → 속도 선택
3. 씬별로 나레이션이 생성됩니다. 오래 걸려도 그대로 두면 됩니다.
   **중간에 끊겨도 다시 실행하면 만든 부분은 건너뛰고 이어서 합니다.**
4. 끝나면 캡컷을 열어 초안(`폴더이름_자동배치`)을 확인하세요.
5. 마지막으로 그 폴더를 `review.bat` 에 드래그해서 검수하면 완벽합니다.

## 결과물 (프로젝트 폴더 안 `출력` 폴더)

- `나레이션_전체.wav` — 전체 나레이션 (씬별 파일은 `씬오디오` 폴더)
- `자막.srt` — 나레이션 타이밍에 맞춘 자막
- `타임라인.csv` — 씬별 시작 시각/길이 표

## 주의

- 2인 대화(掛け合い) 대본(`A: ...` 형식)이면 자동으로 알아채고 역할별 목소리를 물어봅니다.
- 초안 생성 후 **이미지·출력 폴더를 옮기거나 지우면 캡컷 초안에서 깨집니다.**
- 캡컷 초안 폴더를 못 찾으면 경로를 물어봅니다: 캡컷 → 설정 → "초안 위치"의 경로를 붙여넣으세요.
- 캡컷 자동 업데이트는 꺼두는 것을 권장합니다 (버전이 바뀌면 초안 구조가 달라질 수 있음).

## 드래그도 귀찮다면: 클로드에게 말로 시키기

노트북에서 **클로드(Claude Code/데스크톱 앱)를 이 Progream 폴더로 연 다음**, 채팅에

> **"일본 캡컷 자동화 해줘"**

라고만 하면 클로드가 알아서: 프로젝트 폴더 찾기 → 사전 검토 → 목소리 확인 →
TTS 나레이션 생성 → 캡컷 초안 생성 → 최종 검토 리포트 요약까지 전부 대신 해 줍니다.
(전용 스킬이 이 저장소 안에 들어 있어서, 이 폴더에서 연 클로드는 자동으로 이 흐름을 압니다)

단, 폰이나 웹 채팅에서는 안 됩니다 — 캡컷과 파일이 노트북에 있기 때문에,
**노트북에서 이 폴더를 연 클로드**여야 합니다.
