# 일본판 브루 자동화 파이프라인 실행

한국판 `vrew-auto` 스킬의 일본 채널 버전. 사용자가 브루에서 일본어 대본 → 일본어 TTS까지
만들어 저장한 .vrew 파일을 받아, `E:\자동화 프로그램\VREW\vrew_tool.py` 도구로 나머지
편집을 자동 처리한다. 사용자는 비개발자인 한국인이므로 결과 보고는 쉬운 한국어로 하고,
**일본어 자막·문장을 인용할 때는 반드시 한국어 해석을 병기한다.**

## 한국판과 다른 점 (요약)

| 항목 | 한국판 (vrew-auto) | 일본판 (이 스킬) |
|---|---|---|
| 한글숫자→아라비아 자막 변환 | 켬 | **끔** (`--no-numbers`, 일본어 미지원) |
| 자막 교정 | 켬 | **끔** (`--no-rules`, 한국어 맞춤법 규칙이라 일본어에 적용 금지) |
| 음성 검수 리포트 | 도구가 생성 | **끔** (`--no-report`) → Claude가 직접 일본어 기준으로 점검 (2.5단계) |
| 그림/영상 배치·스톡·글자 크기 150·타임라인·배치위치 | 동일 | 동일 (언어 무관) |
| 업로드 전 검토 | 없음 | 검토리포트 프로그램(japan_review) 연계 (2.5단계) |

## ⚙️ 최초 1회 설정 (경로 확정 — 아직 미확정)

아래 세 경로는 일본 채널용으로 아직 확정되지 않았다(2026-09-05 기준). **이 스킬을 처음
실행할 때 사용자에게 확인하고, 확인받은 실제 경로로 이 SKILL.md의 해당 부분을 직접
수정·저장한 뒤 이 문단을 지운다.**

1. **일본용 .vrew를 넣어두는 폴더** — 한국판과 같은 `E:\자동화 프로그램\해줘 폴더`를 같이 쓰는지, 일본 전용 폴더가 따로 있는지
2. **일본 채널 대본 출력 폴더** — 한국판의 `E:\Channel1\output\`에 해당하는 일본 채널 폴더 (일본 대본 스킬이 06_scene-mapping.txt 등을 저장하는 곳)
3. **일본 채널 그림/영상 보관 폴더** — 한국판의 `E:\탄탄한 소리경제학\`에 해당하는 폴더

## 1단계: 입력 파일 3가지 찾기

### .vrew 파일
- 사용자가 경로를 줬으면 그것을 쓴다.
- 안 줬으면 위 최초 설정의 **일본용 폴더**(미확정 시 `E:\자동화 프로그램\해줘 폴더` →
  `E:\자동화 프로그램\해줘` → `C:\Users\louki\Downloads` 순서)에서 가장 최근 `*.vrew`를 쓴다.
- 이름이 `_자동화.vrew`로 끝나는 파일은 이미 처리된 결과물이므로 항상 제외한다.
- **파일을 고른 뒤 자막 텍스트가 일본어인지 반드시 확인한다.** 한국어가 대부분이면
  "이 파일은 한국 영상 같은데 일본판으로 처리할까요?"라고 사용자에게 먼저 확인한다
  (한국판·일본판 파일이 같은 폴더에 섞여 있을 수 있다).
- 어떤 파일을 골랐는지 반드시 사용자에게 알린다.

### 매칭표 (06_scene-mapping.txt)
- 최초 설정의 **일본 채널 출력 폴더** 아래 회차 폴더들에서 `06_scene-mapping.txt`
  (없으면 `씬별_대본매칭.txt`)를 찾는다.
- 회차 폴더 고르는 순서는 한국판과 동일하다:
  1. 사용자가 회차를 말한 경우(`9.5-no.1`, `no.1`, `어제 1번`) → 폴더명과 직접 대조
  2. 사용자가 주제를 말한 경우 → 각 폴더 `_HANDOFF.md` 첫 줄과 대조 (없으면 폴더명)
  3. 아무 말도 없으면 `.vrew` 파일명 키워드로 1·2번 대조
  4. 그래도 못 정하면 가장 최근 수정 폴더
- ⛔ 같은 날짜 회차가 여럿이면 추측하지 말고 반드시 사용자에게 물어본다.
- 어떤 폴더(주제)를 골랐는지 반드시 사용자에게 먼저 알린다. 주제가 일본어면 한국어 해석 병기.

### 그림/영상 폴더
- 최초 설정의 **일본 채널 그림 폴더** 아래를 하위 폴더까지 재귀적으로(2~3단계) 뒤져서,
  씬 번호 붙은 그림(scene_NN.jpg, 씬N.jpg 등)이 들어있는 폴더 중 가장 최근 것을 고른다.
  폴더 이름·위치가 수시로 바뀌므로 경로 일치에 의존하지 않는다.
- `씬N.mp4` 영상이 있으면 해당 씬은 그림 대신 영상(최대화·음소거)이 들어간다.

후보가 여러 개라 확신이 없으면 추측하지 말고 사용자에게 짧게 물어본다.
매칭표나 그림 폴더를 못 찾으면: 그림 배치는 빼고 나머지만 실행한 뒤, 뭘 못 찾았는지 알려준다.

## 1.5단계: 픽셀스 스톡 영상 준비 (기본 실행)

한국판과 같은 방침: 전체 씬의 **35%는 픽셀스 스톡 실사 영상**. "스톡 빼줘"면 건너뛰고,
"스톡 20%로"면 그 비율을 따른다.

1. 매칭표의 씬 수 N에서 목표 개수 = round(N × 0.35).
2. `씬N.mp4`(사용자가 만든 영상)는 절대 건드리지 않는다. 남은 씬 중 실사에 어울리는 씬만
   고른다 (도시 풍경·거리·군중·사무실·항구 ⭕ / 초현실·비유·일러스트 장면은 사용자 이미지 유지).
3. **일본 시청자용 영상이므로**, 장면이 일본 국내 배경이면 검색어에 japan/tokyo/osaka 등을
   넣어 일본 느낌 영상을 우선한다 (예: "tokyo street crowd"). 중국·미국 등 다른 나라가
   주제인 씬은 그 나라 검색어를 쓴다.
4. 다운로드: `python "E:\자동화 프로그램\VREW\vrew_tool.py" --stock "<영어 검색어>" "<그림폴더>\씬N.mp4"`
   결과 없으면 검색어를 일반화해 1회 재시도, 그래도 없으면 사용자 이미지 유지.
5. API 키: `E:\자동화 프로그램\VREW\pexels_api_key.txt` (한국판과 공용, 무료 한도 월 2만 회).

## 2단계: 실행

```
python "E:\자동화 프로그램\VREW\vrew_tool.py" "<vrew 경로>" --scenes "<매칭표 경로>" --images "<그림 폴더>" --no-numbers --no-rules --no-report
```

- `--no-numbers --no-rules --no-report`는 **일본판 필수 플래그**다. 빼먹으면 한국어 전용
  규칙이 일본어 자막을 망가뜨릴 수 있다.
- 그림 배치를 뺄 때는 `--scenes`/`--images` 없이 실행한다.
- 결과물 (원본은 그대로 둠): `<이름>_자동화.vrew`, `<이름>_타임라인.txt`, `<이름>_배치위치.txt`
- 실행 로그 끝에 "자체 검증(무결성): 통과 ✓"가 나와야 정상이다.
- ⚠️ `씬 시작 위치: N/N개 찾음`의 분모·분자가 같아야 한다. 다르면 그림이 빠진 채로 나온다.
  (매칭표의 씬 시작 문장은 일본어 그대로 자막과 대조되므로 원리는 한국판과 같다.)
- ⚠️ **클립 나누기 점검 (일본판 첫 실행 시 특히)**: 로그의 클립 수 변화를 확인한다.
  일본어 문장은 「。」「？」「！」로 끝나는데 도구가 이를 인식하지 못해 나누기가 0건이거나
  어색하게 나뉘면 → 사용자에게 알리고, `vrew_tool.py`에 일본어 문장부호 지원을 직접 추가한
  뒤 다시 실행한다 (아래 "알려진 한계" 참고). 수정이 어려운 상황이면 `--no-split`로 다시
  만들어 나누기 없이 전달한다.

## 2.5단계: 일본어 품질 점검 (일본판 전용 — 항상 실행)

한국판의 자막 교정·음성 검수를 대신하는 단계다.

1. **Claude가 직접 자막 텍스트를 점검**해 `<이름>_음성검수.txt`를 작성한다:
   - **한글 혼입** (일본어 TTS·자막에 한글이 섞이면 업로드 사고 — 최우선 확인)
   - 반각 카타카나(ｶﾀｶﾅ), 이모지, 마크다운·지시문 잔재
   - 위험 발음 구간: 읽기가 갈리는 한자(行った, 大分, 一日 등), 숫자+조수사, 날짜·고유명사
   - 항목마다 해당 자막(일본어)과 한국어 해석, 확인 방법을 쉬운 말로 적는다.
2. **검토리포트 프로그램 연계**: 컴퓨터에 Progream 저장소의 `japan_review.py`(review.bat)가
   설치돼 있으면, 회차 폴더를 대상으로 실행해 `검토리포트.html`의 ❌ 오류 항목만 요약해
   전달한다. 설치돼 있지 않으면 건너뛰고, 업로드 전에 돌려보라고 한 줄 안내만 한다.

## 3단계: 결과 보고

쉬운 한국어로 짧게 정리한다 (일본어 인용에는 한국어 해석 병기):

- 그림 몇 장 / 영상 몇 개가 배치됐는지
- 클립이 몇 개에서 몇 개로 나뉘었는지
- **숫자 변환은 하지 않았다는 점** (일본판은 대본 단계에서 아라비아 숫자를 유지하는 방침)
- **영상 총 길이와 챕터 타임코드** — `_타임라인.txt`의 "유튜브 설명란 복사용" 블록을 그대로
  보여준다 (실측값). `04_upload-info.md`의 타임코드는 추정치라 어긋날 수 있으니 실측값으로
  교체하라고 안내한다. 챕터 실측은 매칭표와 같은 폴더의 `04_upload-info.md`에
  `0:00 소제목 - 시작 문장` 형식이 있어야 된다 (다른 위치면 `--chapters "<경로>"`, 빼려면 `--no-timeline`).
- **영상이 들어간 클립 번호 표 (필수, 사용자가 묻기 전에 항상)** — `_배치위치.txt`의
  "[영상이 들어간 씬]" 블록을 표(클립 번호 | 타임코드 | 씬 | 파일 | 시작 자막+한국어 해석)로 보여준다.
  그림 배치 위치는 파일 경로만 안내한다.
- 2.5단계 점검 결과 요약 — 특히 **한글 혼입이 1건이라도 있으면 가장 위에 강조**한다.
- 완성 파일 경로 — "브루에서 이 파일을 여세요"
- 글꼴 한 줄 안내: 글자 크기 150은 적용됐지만, **글꼴이 일본어 지원 글꼴(Noto Sans JP 등)인지**
  브루에서 한 번 확인하라고 안내한다 (한국어 글꼴이면 일부 한자·가나가 깨져 보일 수 있다).
- 로그의 ⚠ 경고와 "씬 번호가 없어 건너뛴 파일" 목록이 있으면 그대로 전달한다.

## 추가 요청 대응

- **TTS용 대본 변환 (일본어)**: "일본 대본 TTS용으로 바꿔줘"라고 하면, 도구의
  `--tts-script`는 **한국어 전용이므로 쓰지 않는다.** 대신 Claude가 직접 일본 채널 최신
  회차의 `03_script.md`(또는 사용자가 준 대본)를 읽고, TTS가 잘못 읽기 쉬운 구간만
  가나 표기로 바꾼 `_TTS用.txt`를 만든다 (예: 읽기가 갈리는 한자·연호·고유명사).
  일본어 TTS는 아라비아 숫자를 대체로 잘 읽으므로 숫자 전면 변환은 하지 않는다.
- **썸네일 검수**: 한국판과 같은 명령을 쓴다 (썸네일 경로 + 일본어 대본/vrew 경로).
  결과 보고에서 일본어 문구는 한국어 해석을 병기한다.
- **스톡 조절**: "스톡 빼줘"(생략), "스톡 20%로"(비율), "씬 12에 스톡 넣어줘"(씬 지정).
- **일부 기능만**: `--no-split`(나누기 제외) `--no-font`(글자 크기 제외)
  `--no-timeline`(타임라인 제외) `--chapters "<경로>"`(챕터 파일 지정)
  `--anim`(기존 그림 애니메이션 랜덤). ⚠️ `--no-numbers --no-rules --no-report`는 항상 유지.
- 도구 자체를 고치거나 기능을 추가하는 요청이면 이 스킬 범위 밖이므로
  `E:\자동화 프로그램\VREW\vrew_tool.py`를 직접 수정한다 (메모리의 vrew-automation-project 참고).

## 알려진 한계 (도구 업그레이드로 없앨 것들)

`vrew_tool.py`는 한국어 기준으로 만들어져 있어, 일본판은 아래 기능을 아직 도구로 못 한다.
필요해지면 이 스킬을 실행하는 세션이 `vrew_tool.py`에 일본어 모드를 직접 추가한다:

1. **자막 숫자 변환** — 한자·가나 숫자 → 아라비아 숫자 (현재 미지원 → 대본 단계에서 아라비아 숫자 유지로 대응)
2. **일본어 자막 교정 규칙** — 현재 미지원 → 검토리포트 프로그램(japan_review)으로 대체
3. **일본어 음성 검수** — 현재 미지원 → Claude가 2.5단계에서 직접 수행
4. **클립 나누기의 일본어 문장부호(。？！) 처리** — 첫 실행 때 동작 확인 필요
